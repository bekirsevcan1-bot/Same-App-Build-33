---
name: Profile media visibility
description: Visibility rules for customer and provider profile photos.
---

Provider portfolio photos are public on the provider profile so customers can evaluate completed work. Customer personal photos remain private by default and are managed separately from provider portfolio media.

**Why:** Customers need proof of a provider’s work, while personal customer imagery should not become public accidentally.

**How to apply:** Keep profile photo, customer personal media, and provider portfolio media as separate collections with separate access and UI labels.
